# Quick Start

## 1. Clone the repo

```bash
git clone https://github.com/stefanoskarakasis/Product-Marketing-Skills.git
cd Product-Marketing-Skills
```

## 2. Build your brain

Open Claude Code, Claude Cowork, Cursor, or Windsurf in this repo and run
the `product-marketing-context` skill. It walks you through:

- Product context (what you sell, to whom)
- ICP (company size, persona, pain points, buying triggers)
- Alternatives and positioning
- Voice and tone
- Market context
- Proof points

Takes about 15 minutes. Answers save to `/foundation/brain.md`.

## 3. Run a skill

Once your brain exists, any brain-dependent skill in this repo reads it
automatically. Try:
- "Generate positioning for our platform" 
- "What tier is this launch?" 
- "Run a retro on our last launch"

## What You Can Do (21 skills across 6 plugins)

See the [main README](./README.md) for the full skill list and what each
plugin covers.

## Troubleshooting

**"I want to run a skill but haven't built my brain yet."**
Most skills will still run — they'll ask you a few direct questions instead
of reading the brain, and tell you the output would be sharper with a brain
in place. Build the brain with `product-marketing-context` whenever you're
ready.

**"Can I use this with Claude Code CLI, Cursor, Claude Cowork, etc.?"**
Yes — these skills follow the [Agent Skills spec](https://agentskills.io/)
and work with any agent that supports it.
