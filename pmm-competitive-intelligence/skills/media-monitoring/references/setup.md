## 1. The five questions

Ask once, in one message, pre-filled from brain Section 3.

1. **Core competitors?** Up to 5. Confirm or edit the pre-filled list.
2. **Who reads it?** Default VP Product Marketing.
3. **Where should it land?** Chat, Slack channel, a Doc.
4. **How often?** Default a weekly sweep plus a monthly review.
5. **What makes you act?** Up to three triggers (pricing, leadership hires, product launches, funding, messaging).

Also ask for up to 3 category themes (optional) and confirm your own company is on the watch list.

## 2. Executor and backup

- Both are required. Setup does not finish without them.
- The executor sets up, reviews and approves. The backup can run the sweep and approve when the executor is away.
- Their Slack handles are saved in `watchlist.md`; only they can say `go` or `post`.
- `handover` changes either one.

## 3. Channels and the ladder

Up to 8 channels per competitor, for example: pricing page, changelog, newsroom or blog, careers page, filings or funding, review sites, partner pages, social.

For each channel try, in order:

1. A connector (`~~web research`, `~~company data`, `~~market data`, `~~reviews`).
2. Built-in search and fetch.
3. A logged-out browser, where one is available.
4. Ask for a paste.

Record each rung tried in `_state.md`.

## 4. The preflight

Test every channel for every competitor and show a grid: ✅ working, ⚠️ partial, 🚫 blocked, n/a. Then show the next best fix (a paste list for blocked channels, a connector that would add reach). Do not start the first sweep until the grid is shown.

## 5. Paste-first mode

If fetch and connectors are unavailable, the whole skill works from pasted pages or a weekly export. The brief has the same shape and the coverage line names what was not pasted.

## 6. Schedule

- A weekly sweep (for example Monday 08:00) and a monthly review (first Monday).
- A scheduled run never asks questions and never runs `setup`.
- Offer, never create, the schedule: tell the user how to set it up with the scheduling tools in their environment.

## 7. Slack commands

- `what did the monitoring catch this week`
- `monitor status`
- `add [competitor] to the watchlist` (executor and backup only)
- `acted M-id`, `useful M-id`, `noise M-id`, `mute [topic]`
- `we missed this`

## 8. Terms-restricted sources

Professional-network pages, review platforms and job boards that forbid automated access are read by paste only. Never log in on the user's behalf. Pasted material that looks like non-public information about a listed company is flagged and not used.
