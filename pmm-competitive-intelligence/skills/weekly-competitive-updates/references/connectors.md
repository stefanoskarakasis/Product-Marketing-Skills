# Connectors

Reference for `weekly-competitive-updates`.

| Connector | What it adds | Feeds |
|---|---|---|
| `~~web research` | Open-web search and page fetch for competitor releases, blogs, filings and transcripts | Sweep |
| `~~company data` | Funding, headcount and hiring moves | Sweep |
| `~~market data` | Competitor traffic shifts | Sweep |
| `~~reviews` | Public review themes (paste only today) | Sweep |
| `~~team chat` | Where the update is posted | Delivery |
| `~~cloud storage` | The shared Doc | Delivery |

Connectors are read-only. A pulled fact is a draft: it carries the category, the tool, the link and the retrieval date. This skill never reads a CRM: the update uses public sources only.
