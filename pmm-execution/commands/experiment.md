# /pmm-execution:experiment -- Experiment Doc

Build a rigorous growth experiment document, or pressure-test one you
already have, using ICE scoring and proven growth frameworks.

## Invocation

```
/pmm-execution:experiment Test a shorter signup form
/pmm-execution:experiment Does adding social proof to pricing make sense to
test?
```

## Workflow

Uses the `experiment-doc` skill. Scores the experiment idea, enforces
named stakeholders and guardrail metrics, and only produces a full
document once the idea clears a minimum rigor bar.
