# /pmm-execution:okrs -- Quarterly OKRs

Build a complete, export-ready OKR set for a PMM team — Objective, Key
Results, supporting projects, and a scorecard.

## Invocation

```
/pmm-execution:okrs Q3 2026
/pmm-execution:okrs Build OKRs for the positioning refresh initiative
```

## Workflow

Uses the `pmm-okrs` skill. Walks through defining the Objective,
stress-tests each proposed Key Result for measurability, and produces
the full OKR document plus exec-summary language.
