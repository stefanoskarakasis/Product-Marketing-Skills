# /pmm-execution:pre-mortem -- Pre-Mortem

Run a cross-functional pre-mortem on a project before it launches —
imagining it has already failed, then working backward to find the real
risks before they happen.

## Invocation

```
/pmm-execution:pre-mortem New pricing tier launch
/pmm-execution:pre-mortem Enterprise SSO rollout
```

## Workflow

Uses the `pre-mortem` skill. Facilitates the "imagine it failed"
exercise across functions, categorizes the risks that surface, and
produces a mitigation plan for the highest-severity ones.
