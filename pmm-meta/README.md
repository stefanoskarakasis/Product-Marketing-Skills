# pmm-meta

Meta skills that operate on the skill system itself: skill review, session learning, cross-skill synthesis and output verification.

## Start here

- Checking an output before it ships? → `/pmm-meta:meta-verify`
- Auditing a skill against the standard? → `/pmm-meta:meta-review`
- Logging what a session taught you? → `/pmm-meta:meta-learn`
- Looking for patterns across sessions? → `/pmm-meta:meta-synthesis`

> [!NOTE]
> 💬 **Try it:** "Verify this output against the skill that produced it: [paste]"
>
> 🧠 **Brain:** 1 of 4 skills reads your brain (`product-marketing-context`): `meta-synthesis`. The others work without one.

## Skills (4)

- **meta-learn** — Capture what a finished skill session taught you as falsifiable patterns and log it for meta-synthesis.
- **meta-review** — Audit any SKILL.md against the repo's authoring standard and get a scored checklist with prioritized fixes.
- **meta-synthesis** — Find patterns repeating across sessions, propose guardrails and brain updates, and see adoption per skill weekly.
- **meta-verify** — Run a second-pass quality check on a skill's output before it goes out, with specific fixes.

## Commands (4)

- `/pmm-meta:meta-learn` — Run post-session learning extraction for any skill.
- `/pmm-meta:meta-review` — Audit a skill's SKILL.md against the authoring spec.
- `/pmm-meta:meta-synthesis` — Detect cross-skill patterns and propose brain updates.
- `/pmm-meta:meta-verify` — Run a second-pass quality check on skill output.

## Connectors

> [!TIP]
> 🔌 **This plugin needs no connectors.**
>
> 📋 It works on your own outputs and needs no external tools.
