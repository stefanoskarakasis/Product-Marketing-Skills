# pmm-positioning

Strategic positioning and messaging using April Dunford's framework — with five output modes.

## Skills (1)

- **positioning-messaging** — Build or audit positioning statements, messaging hierarchies, homepage copy, sales persona cards, and competitive decks using the full Dunford sequence.

## Commands (1)

- `/pmm-positioning:positioning-messaging` — Build or audit positioning and messaging. Supports five modes (build, audit, fletch, sales-enablement, homepage) — the right one runs based on what you ask for.
