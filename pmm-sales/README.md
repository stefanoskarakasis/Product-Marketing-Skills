# pmm-sales

Sales skills for sellers and CSMs, built for Slack first: tag Claude in a thread and get the state of a customer, the reason to contact a prospect, the next step on a deal, the next line for an objection or a scored discovery call, every line sourced.

## Start here

- Researching a company you do not sell to yet? → `/pmm-sales:prospect-research`
- Catching up on a customer before a renewal? → `/pmm-sales:customer-context`
- Live deal that might stall? → `/pmm-sales:deal-review`
- Discovery call coming up? → `/pmm-sales:discovery-call-prep`
- Discovery call just ended? → `/pmm-sales:discovery-call-scoring`
- Buyer just pushed back? → `/pmm-sales:objection-handling`
- Need a one-pager, demo script, proposal or win-loss read? → `/pmm-sales:sales-collateral`
- Weekly report for the PMM? → `/pmm-sales:sales-research-digest`

> [!NOTE]
> 💬 **Try it:** "@Claude catch me up on Northwind before Thursday's renewal call"
>
> 🧠 **Brain:** all 8 skills read your brain (`product-marketing-context`).

## Skills (8)

- **customer-context** — Get the state of one customer before a call, renewal, escalation or handover, or ask one quick question about them.
- **prospect-research** — Find out if there is a reason to contact one company, with an angle, a first question and a fallback.
- **deal-review** — Check if one live deal is real and what could kill it, debrief a call, or see which deals need you this week.
- **discovery-call-prep** — Get a point of view and a seven-stage plan for a discovery call, or plan the next one from the last transcript.
- **discovery-call-scoring** — Score a discovery call you ran, see what cost you, get moves for the next one and track if you are improving.
- **objection-handling** — Get the next line for a buyer objection, a call digest, an email reply or a prep list, and build a library from your calls.
- **sales-collateral** — Build a one-pager, demo script, proposal, ROI calculator or win-loss read from your brain, or get sent to the skill that owns the asset.
- **sales-research-digest** — Get the PMM's weekly report on how sellers used the research skills, whether the advice held and three actions.

## Commands (8)

- `/pmm-sales:customer-context` — Get the current state of one customer.
- `/pmm-sales:prospect-research` — Get the reason, angle and first question for one prospect.
- `/pmm-sales:deal-review` — Review one live deal and get the next step.
- `/pmm-sales:discovery-call-prep` — Get the plan for a discovery call.
- `/pmm-sales:discovery-call-scoring` — Get your discovery call scored and coached.
- `/pmm-sales:objection-handling` — Get the next line for a buyer objection.
- `/pmm-sales:sales-collateral` — Build a sales asset or a win-loss read.
- `/pmm-sales:sales-research-digest` — Get the weekly report on how the sales research skills are used.
