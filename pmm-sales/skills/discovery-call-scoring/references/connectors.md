# Connectors

Optional. A pasted transcript works with none of these. Names are categories (`~~`); the team's tool fills each. Setup and approvals belong to the team, not this skill.

| Category | Used for | Read or write |
|---|---|---|
| `~~call recordings` | The seller's own finished call, any recorder (Gong, Fireflies, Fathom, Zoom, Meet, Teams) or a transcript file in a folder | Read only |
| `~~calendar` | Call number, length, attendees, why they agreed to meet | Read only |
| `~~CRM` | Stage and prior calls, for call number and bar | Read only |
| `~~knowledge base` | The brain and `/context/` files (Drive, Notion, GitHub) | Read; writes only to the files in `rules.md` |

Rules:

- Read only the call the seller names or the latest one of theirs. Never search other sellers' calls.
- Whether recordings may be read is the company's decision, recorded by the discovery owner with role and date and asked again after 90 days. Until then, only what the seller pastes.
- Pulled facts are drafts, tagged with category, tool and date. A refusal is shown, not retried.
