# Switching risk: seed cards

Seed cards. Plan the move; never promise what the implementation lead has not confirmed.

Every card: **Heard** (the buyer's words), **Real issue**, **Ask**, **Say**, **Prove**, **Route**. Method: `../method.md`.

## SW-01 Migration

- **Heard:** "Moving our data will be painful."
- **Real issue:** A fear, based on a past move.
- **Ask:** "What did the last migration cost you?"
- **Say:** "Tell me what went wrong last time. We can plan against exactly that."
- **Prove:** Migration facts, if approved; otherwise "unverified"
- **Route:** Implementation lead
- **Status:** seed

## SW-02 Lock-in

- **Heard:** "We don't want to be locked in."
- **Real issue:** A contract worry or a data worry.
- **Ask:** "What would getting out need to look like?"
- **Say:** "What exit would feel fair to you?"
- **Prove:** Contract and export terms from the approved list; otherwise "unverified"
- **Route:** Legal, deal desk
- **Status:** seed

## SW-03 Long implementation

- **Heard:** "Implementation takes too long."
- **Real issue:** A timeline deadline.
- **Ask:** "What date are you working to, and why?"
- **Say:** "What is the date, and what's driving it? Let's see what's realistic."
- **Prove:** Timelines, if approved; otherwise "unverified"
- **Route:** Implementation lead
- **Status:** seed

## SW-04 Downtime

- **Heard:** "We can't have downtime."
- **Real issue:** A hard operational constraint.
- **Ask:** "Which hours or processes cannot stop?"
- **Say:** "Which processes can't stop, and for how long?"
- **Prove:** Cutover facts, if approved; otherwise "unverified"
- **Route:** Implementation lead, Solutions
- **Status:** seed
