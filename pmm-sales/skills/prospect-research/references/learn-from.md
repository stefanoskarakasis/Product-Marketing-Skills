## Rules

1. Every learned item is shown with the skill it came from and its date, on one "Learned from" line. No source, no use.
2. Learned items shape the hypothesis, the angle and the questions. They never become proof of ours; proof comes only from `proof-points` as approved.
3. A learned item that conflicts with a confirmed brain value is shown as a question with both values.
4. A seller-reported outcome is labelled seller-reported. Counts below the n in `feed-forward.md` are shown as notes, never as a trend.
5. Customer or competitor material never carries names, amounts or quotes tied to a person into a prospect brief.
6. If none of these exist, say so in one line and continue: "No earlier skill output found. Built from the brain and the web."
