# Connectors

Read at Pre-flight. Categories, not vendors. Each team connects its own; this skill uses whatever answers a cheap read and says what it did not query.

| Category | Used for | Read or write |
|---|---|---|
| `~~CRM` | Opportunity stage, loss reasons, outcomes | Read only |
| `~~call recordings` | Transcripts for win-loss | Read only, after the owner's decision |
| `~~win/loss` | Structured buyer interviews and win-loss reports | Read only |
| `~~calendar` | Audience, attendees, follow-ups | Read only |
| `~~team chat` | A Slack card in the tagged thread | Reply only |
| `~~cloud storage` | Saving the full asset as a doc; the ROI calculator and win-loss table as a sheet; existing collateral | Write only where the user asked |
| `~~knowledge base` | Where the brain or existing collateral lives | Read only |

## Owner's decision

Reading call recordings and CRM outcomes is the owner's decision, per source, recorded with role and date, and asked again after 90 days. Until then the skill uses only what a seller pastes or uploads. The owner sees the risks first: consent, works councils, personal data, retention and CRM quality.

## Without connectors

Pasted notes, transcripts and exports give the same shape. State which sources were and were not read.
