# /pmm-toolkit:brief -- GACCS Brief

Build and pressure-test a complete GACCS brief for any marketing, GTM,
or enablement project.

## Invocation

```
/pmm-toolkit:brief Q3 product launch campaign
/pmm-toolkit:brief Customer webinar series
```

## Workflow

Uses the `gaccs-brief` skill. Works in conversational mode (idea-first)
or brain-dump mode (context-first, if you paste in raw notes), and
challenges any weak section inline before producing the final brief.
