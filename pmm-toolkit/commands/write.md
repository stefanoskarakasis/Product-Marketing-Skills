# /pmm-toolkit:write -- Writing Assistant

Rewrite, sharpen, or draft any written communication — Slack messages,
emails, decision memos, homepage copy — with behavioral-science
pressure-testing built in.

## Invocation

```
/pmm-toolkit:write [paste a draft to sharpen]
/pmm-toolkit:write Draft a Slack update on the launch delay
```

## Workflow

Uses the `writing-assistant` skill. Diagnoses what's weak about the
current draft (or drafts from scratch), then rewrites it and explains
the reasoning behind the changes.
