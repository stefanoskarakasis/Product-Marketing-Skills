# commands/ — writing-assistant


Available commands:

- `/writing-assistant:email` — Draft or rewrite a professional email — internal or external
- `/writing-assistant:slack` — Draft or sharpen a Slack message or async update
- `/writing-assistant:homepage` — Write or rewrite homepage or landing page copy
- `/writing-assistant:deck` — Write or sharpen copy for a presentation, sales deck, or pitch
- `/writing-assistant:one-pager` — Write a one-pager — solution brief, battle card leave-behind, or executive summary
- `/writing-assistant:cold-email` — Write a cold outreach email or short sequence
