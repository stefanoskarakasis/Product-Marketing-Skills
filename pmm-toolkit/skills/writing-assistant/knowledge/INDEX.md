# Knowledge INDEX

This is the router. Read this first. Load only the subfolder(s) relevant to the
current task. Do not load everything at once — context windows are finite and
loading irrelevant files wastes attention.

---

## Subfolders

### craft/
**Load when:** Running a Behavioral Messaging Review (Mode 3), or when the user asks
why something isn't landing and you need confirmed patterns to draw from.
**Contains:** `patterns.md` — messaging moves with evidence behind them. These are
promoted from hypotheses that have been confirmed across 3+ sessions.

### false-beliefs/
**Load when:** The user references conventional writing advice, asks "should I..." or
"is it better to..." questions, or when you're about to recommend something that may
contradict established wisdom.
**Contains:** `catalog.md` — beliefs killed by data. Before recommending something
standard, check here first.

### hypotheses/
**Load when:** End of session (Learning Mode), or when the user asks "what have you
learned" or "what patterns are you tracking."
**Contains:** `active.md` — live hypotheses being tested, with current evidence and
signal strength. Update here during Learning Mode.

### sessions/
**Load when:** End of session only (Learning Mode, Step 3).
**Contains:** `log.md` — brief session records. Append, never rewrite.

---

## Loading discipline

One task = one subfolder (usually). If a session spans multiple modes, load
progressively as needed. Never preload all subfolders at the start of a session.
