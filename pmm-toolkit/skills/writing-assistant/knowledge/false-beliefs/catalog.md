# False Beliefs Catalog

These are things conventional writing advice says matter.
Repeated use, user corrections, or data has shown otherwise.

Before recommending a standard approach, check here. If it appears, apply the
corrected understanding instead — or flag the tension explicitly.

---

| ID | Belief | What actually happened | Date killed |
|----|--------|----------------------|-------------|
| FB-001 | "Always open with context before the ask" | Exec recipients consistently edited out the context preamble and kept only the decision or ask. Decision-first structure was accepted without revision in the same situations. | 2026-03-18 |
| FB-002 | "Bullet points improve scannability in all messages" | In short 1:1 messages (Slack, brief email), bulleted versions were perceived as colder and more formal than intended. Paragraph versions preserved the human tone and were preferred without prompting. Bullets remain valid for genuinely list-like content in longer documents. | 2026-03-18 |
