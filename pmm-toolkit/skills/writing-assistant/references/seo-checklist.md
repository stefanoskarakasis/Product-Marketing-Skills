# SEO checklist

For blog posts and landing pages. Write for the reader first, then run this list.

## Keywords

- One primary keyword and a few secondary ones per page.
- Put the primary keyword in the headline, the first paragraph, one subheading, the meta
  description, and the URL slug. Use the secondary keywords where they read naturally.
- Never stuff. If a sentence reads worse with the keyword, drop the keyword.
- Never state search volume, difficulty, or rankings you were not given. Use
  `[PLACEHOLDER: figure from your SEO tool]`. If the user pastes keyword data, use it and
  name where it came from.

## On-page elements

| Element | Guidance |
|---|---|
| Title tag | About 60 characters or fewer, so it shows in full. Primary keyword near the front. |
| Meta description | About 155 to 160 characters or fewer. Includes the primary keyword and gives a reason to click. |
| URL slug | Short and descriptive, with the primary keyword. |
| H1 | One per page. Matches or closely reflects the title tag. |
| H2 and H3 | Descriptive. Secondary keywords where they fit. |
| Image alt text | Describe the image. Include the keyword only if it is true to the image. |
| Internal links | Link to related pages on the same site where the reader would want a next step. |
| External links | Link out to a primary source when citing a fact. |

## Snippet-friendly structure

Where a section answers a direct question, shape it so it can be lifted: a one or two
sentence definition, a numbered list for steps, or a table for comparisons.

## Output for the SEO block

Title tag, meta description, URL slug, secondary keywords used, internal link ideas,
sources worth citing, alt-text ideas, and any snippet-shaped section.
