# Social post

## Inputs beyond the shared set

- **Platform (required):** LinkedIn, X, Instagram, or Facebook. If the user didn't say,
  ask. The platform changes the length, the hook, and the format.

## Platform notes

Platforms change their limits and layouts. Confirm the current limit before publishing.

- **LinkedIn.** Only the first few lines show before "see more", so the hook has to work
  there. Short paragraphs, a human tone, a personal angle over a press-release one.
- **X.** A hard character cap (280 on standard accounts). One idea. Use a thread only if
  the story needs it, and make each post in the thread stand on its own.
- **Instagram.** The caption supports an image or video. Open with the hook, use line
  breaks, put tags at the end.
- **Facebook.** Conversational. A direct question tends to draw replies.

Default length: LinkedIn about 600 to 1,000 characters; X inside the cap; Instagram a
short caption; Facebook a few sentences.

## Structure

1. **Hook.** The first line. Offer two hook options when the user hasn't set a tone.
2. **Body.** Two to four short points, or a short story.
3. **CTA.** One: comment, click, share, or reply. Not a pile of them.
4. **Tags.** Only where they help discovery, three at most.

## Rules

- No em dashes.
- No emoji in the hook unless the voice uses them.
- Real numbers only. A stat without a source is a placeholder.
