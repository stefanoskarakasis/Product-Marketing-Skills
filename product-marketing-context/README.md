# pmm-foundation

The PMM brain — builds and maintains `/foundation/brain.md`, the GTM
context file every other plugin in this stack reads before producing
output.

## Skills (1)

- **product-marketing-context** — Build and maintain the shared GTM brain:
  product context, ICP, positioning, voice, market context, and proof
  points.

## Commands (1)

- `/pmm-foundation:build-brain` — Run the brain-building wizard end to end.
