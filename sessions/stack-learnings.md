## How the System Uses This

1. **Meta-learn discovers pattern** → Logs to quality-learnings.md
2. **Pattern emerges** (seen 2+ times) → Also logged to this file under "Emerging"
3. **Pattern confirmed** (5+ times) → Still in "Emerging", but flagged as "ready for promotion"
4. **Meta-synthesis reviews** → Reads this file, sees confirmed patterns
5. **User approves promotion** → Meta-synthesis adds pattern to /context/meta-patterns.yml
6. **Guardrail active** → All future skills load it at pre-flight
